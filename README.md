# Ecommerce Sales Analysis Dashboard

## 📊 Project Overview
This project focuses on analyzing ecommerce sales data using *Power BI* to uncover key business insights regarding sales trends, profit margins, and order categories.

## 🛠️ Tech Stack
* *Tool:* Power BI Desktop
* *Data Source:* Excel / CSV Dataset

## 📈 Key Metrics & Features
* *Total Sales:* 3.32M
* *Total Profit:* 3.07M
* *Total Orders:* 293
* *Average Order Value:* 11.32K
* *Visualizations:* Line charts for monthly trends, Donut charts for payment modes, Bar charts for product categories, and Slicers for city-wise filtering.

  
**##Pipeline to transform raw ecommerce data to meaningful business insights****
* *Data Cleaning (Python & Pandas):* The raw dataset was first processed and cleaned using Python's *Pandas* library. This step involved handling missing values, removing duplicates, and fixing data types.
* *Data Storage & Querying (SQL):* The cleaned data was loaded into a *SQL Database*. Relational queries and joins were utilized to extract aggregated, business-critical insights from the tables.
* *Data Visualization (Power BI):* Finally, the processed data from SQL was connected to *Power BI*. Data modeling was performed to establish relationships, and an interactive dashboard was built to track key performance indicators.
